GeoKuk – součásti třetích stran / Third-party components
==========================================================

GeoKuk je svobodný software pod licencí GNU GPL verze 3 (soubor LICENSE).
Program obsahuje tyto knihovny, každá je pod svou licencí:

|--------------------------------------------|-------------|--------------------------------------------|
| Logback (logback-classic, logback-core)    | 1.3.16      | EPL 1.0 nebo LGPL 2.1                      |
| SLF4J (slf4j-api, jul-to-slf4j)            | 2.0.7       | MIT                                        |
| SQLJet                                     | 1.1.15      | GPL 3 nebo novější                         |
| ANTLR runtime                              | 3.4         | BSD                                        |
| metadata-extractor                         | 2.21.0      | Apache 2.0                                 |
| Adobe XMP Core                             | 6.1.11      | BSD 3-Clause                               |
| SwingX                                     | 1.6.4       | LGPL 2.1                                   |
| Guava, failureaccess                       | 33.4.8, 1.0.3 | Apache 2.0                               |
| Error Prone annotations                    | 2.36.0      | Apache 2.0                                 |
| J2ObjC annotations                         | 3.0.0       | Apache 2.0                                 |
| JSpecify                                   | 1.0.0       | Apache 2.0                                 |
| sqlite-jdbc (s knihovnou SQLite)           | 3.53.4.0    | Apache 2.0, část BSD (Zentus); SQLite je volné dílo |

SQLJet je nabízen pod GPL 2 nebo pod GPL 3 a novější (v jeho jaru jsou
oba texty); GeoKuk ho užívá pod GPL 3 a novější.

Texty licencí, na které tabulka odkazuje:
  GPL 3:      soubor LICENSE
  LGPL 2.1:   https://www.gnu.org/licenses/old-licenses/lgpl-2.1.html
  EPL 1.0:    https://www.eclipse.org/legal/epl-v10.html
  Apache 2.0: https://www.apache.org/licenses/LICENSE-2.0
Licence BSD a MIT jsou celé níže.

Zip pro Windows obsahuje i běhové prostředí Javy (Eclipse Temurin,
OpenJDK) pod licencí GPL 2 s výjimkou Classpath Exception; jeho licence
a upozornění jsou ve složce program/runtime/legal.
