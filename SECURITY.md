# Bezpečnost

## Podporované verze

Opravy bezpečnostních chyb vycházejí jen pro poslední vydanou verzi.

| Verze   | Podpora            |
| ------- | ------------------ |
| 6.x     | :white_check_mark: |
| < 6.0   | :x:                |

## Nahlášení zranitelnosti

Zranitelnost nehlaste veřejným issue. Použijte soukromé hlášení:
[Report a vulnerability](https://github.com/geokuk-community/geokuk/security/advisories/new)
(záložka Security → Advisories).

Uveďte verzi GeoKuku, systém a verzi Javy, postup, jak chybu vyvolat,
a co se tím dá způsobit.

Projekt udržují dobrovolníci. Na hlášení odpovíme obvykle do měsíce.
Když se zranitelnost potvrdí, oprava vyjde v nové verzi na
[Releases](https://github.com/geokuk-community/geokuk/releases)
a hlášení zveřejníme jako security advisory. Když hlášení odmítneme,
napíšeme proč.
